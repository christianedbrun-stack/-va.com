# Executive Virtual Assistant Portfolio

A responsive portfolio built with **HTML** and **CSS**, using a 60/30/10 color scheme:
- Primary (60%): `#5A2A6E`
- Secondary (30%): `#FFFFFF`
- Accent (10%): `#F28C28`

## Features
- Sidebar with profile photo and tagline
- Navigation bar to jump across sections
- Skills with progress bars
- Tools (chips) for quick visual scanning
- Achievements & certificates (with images)
- Testimonials
- Project cards with hover effects
- Contact section with CTA buttons
- Responsive layout (desktop & mobile)

## Getting started
1. Create a folder (e.g., `portfolio-site`).
2. Save `index.html`, `style.css`, and `README.md` into it.
3. Add your images:
   - `profile.jpg`
   - `certificate1.jpg`
   - `certificate2.jpg`
   - `award.jpg`
4. Open `index.html` in your browser.
